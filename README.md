# Sea-level-predictor-with-python
In this Notebook, we will analyze how the sea level has evolved. 
Based on that analysis, we are capable of predicting how it will grow for the next year until the year 2050

## 1 What is it about ?
a- The main purpose of this notebook is to analyze how much the sea level has risen during the past years
b- Then we predicted how much the sea level will be rising for the coming years until 2050

## 2 Which tools are used ?
We used data from the EPA(Environmental Protection Agency)
The analysis was carried in python with Pandas 
The prediction was made with the lineregress function of the scipy
